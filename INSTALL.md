# Install

See the **[Install section in the README](README.md#install)** for the primary instructions.

### One-liners

```bash
# Linux / WSL2
curl -fsSL https://raw.githubusercontent.com/nikhilken14/husk/main/install.sh | bash
```

```powershell
# Windows PowerShell
irm https://raw.githubusercontent.com/nikhilken14/husk/main/install.ps1 | iex
```

### Release zip (clickable on GitHub)

1. [Releases](https://github.com/nikhilken14/husk/releases) → download `husk-*-full.zip`
2. Extract → `./install.sh` or `.\install.ps1`
3. New terminal → `husk`

Replace `nikhilken14/husk` with this project’s GitHub path.
